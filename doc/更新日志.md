## v1.4.3 - 多步骤任务错误保障、二次分析架构升级、Bukkit API 扩展与回复体验优化、AFK 挂机任务系统

### ✨ 新增功能
- 多步骤任务错误保障机制：即使部分步骤失败，也不会中断整个流程
- AnalysisSummary 统一摘要对象：单意图和多步骤任务共享同一结构化格式，便于 LLM 理解和关键词提取
- 统一 LLM 二次分析流程：所有技能执行结果（包括单意图）都经过 LLM 二次分析，回复更自然、能关联上下文
- **AFK 挂机任务系统**：支持 11 个事件监听器的后台监控任务
  - 玩家动态：上线/下线/死亡/传送/等级变化/切换世界
  - 生活行为：进入床/离开床/重生/物品损坏
  - 环境变化：天气变化
  - 双模式：纯通知（直接提醒）+ 回调（自动执行多步骤任务）
  - 自动管理：玩家下线自动取消，任务完成自动清理
  - 命令集成：`/kilacraft afk`（查询）、`/kilacraft afk cancel`（取消）
- 内置词汇表加载：从 JAR 包的 internal/vocabulary/ 目录加载词汇文件
- 三层关键词提取策略：原始查询 + 分词结果 + TF-IDF 关键词，兼容短文本和长文档
- 单字查询优化：支持“弓”、“剑”等单字物品名查询，通过自定义词典和停用词检查
- 结构化结果输出：步骤执行状态标记 [SUCCESS]/[FAILURE]/[SKIPPED]，便于 LLM 二次分析
- AI 回复 Markdown 自动转换：LLM 输出的 Markdown 格式（**加粗**、*斜体*、`代码`）自动转换为 Minecraft 颜色代码
- 连续对话规则增强：新增【实时数据重新获取规则】和【多步骤任务重复规则】，解决代词指代和多步骤截断问题
- **Bukkit API 扩展**：新增 21 个 API，总数达到 58 个（玩家 31 个、世界 20 个、服务器 6 个）
- **多步骤数据传递增强**：API 返回值自动提取到 dataMap，支持后续步骤通过 `{step_x.field}` 引用
- 盔甲装备查询：获取玩家全套盔甲（头盔、胸甲、护腿、靴子），支持多步骤数据传递
- 药水效果查询：查询当前所有药水效果（类型、等级、持续时间）
- 目标方块查询：获取玩家视线指向的方块信息
- 移动状态检测：蹲下/奔跑状态实时查询
- 客户端信息查询：玩家语言设置、显示名称
- 重生点查询：床/重生锚重生位置
- 总经验值查询：累计经验值查询
- 世界详情查询：生物群系、温度、湿度、海平面、实体统计、袭击事件、天气持续时间、世界时间详情

### 🔧 优化改进
- 插件入口类重构：onEnable() 从平铺代码提取为 6 个语义清晰的私有方法，严格保持初始化顺序
- 知识库关键词提取降噪：精准提取用户输入 + 执行结果数据，去除 step_id、状态标签、颜色代码、行首连字符等结构性噪音
- 依赖检查增强：不仅检查依赖步骤是否存在，还检查依赖步骤是否执行成功
- 占位符解析容错：解析失败时跳过该步骤，继续执行后续步骤
- 词汇合并去重：使用 LinkedHashSet 自动去重，合并内置和自定义词汇
- LLM 二次分析提示词优化：分层策略（执行结果=核心事实，知识库=补充，编造=禁止），禁止固定标题模板
- system_prompt 风格定位：热情有趣的玩家朋友风格，回复更生动自然
- 回复长度控制：max_tokens 调整为 500，普通 AI 对话限制 200 汉字
- 配置注释优化：澄清 analysis_prompt_suffix 实际使用场景和关键词提取边界双重用途
- GenericBukkitAPISkill 增强：新增 6 个格式化方法（formatArmorContents, formatPotionEffects, formatBlock, formatBiome, formatRaids, formatWorldTime）
- extractDataFromResult 扩展：支持 ItemStack[]、Set<PotionEffect>、Block、Biome、Collection<Raid> 五类返回值自动提取
- 多步骤兼容性：所有 API description 明确声明可引用的 data 字段
- 安全审查：移除服务器网络信息 API（port, IP, view_distance, idle_timeout），防止敏感信息泄露
- Spigot 1.16.5 兼容性验证：所有 API 基于官方文档验证
- AFK 挂机任务系统优化：工厂模式解耦、上下文一致性优化、延迟反馈不注入历史

### 📚 文档更新
- **服主指南.md / Server Owner Guide.md**：新增挂机任务系统章节（功能展示、使用示例、命令列表）
- **README.md / README.en.md**：核心功能新增挂机任务系统，使用示例新增回调模式
- **AFK 挂机任务系统详解.md**：658 行系统架构文档
- **Bukkit Event 监听器参考手册.md**：642 行详细说明

### ⚠️ 兼容性
- 新增 internal/vocabulary/ 目录用于放置内置词汇文件
- config.yml 中 analysis_prompt_suffix 和 system_prompt 配置更新
- intent_prompts.yml 新增连续对话处理规则（实时数据重新获取 + 多步骤任务重复）
- 新增 21 个 Bukkit API 配置，首次启动时自动创建
