## 快速开始

### 1. 安装

下载最新的 `Kilacraft-AI.jar`，放入服务器 `plugins/` 目录，启动服务器。

### 2. 配置 API

编辑 `plugins/Kilacraft-AI/llm.yml`，填入你的 LLM API 信息：

```yaml
llm:
  api_url: "https://api.deepseek.com/v1/chat/completions"
  api_key: "your-api-key"
  model: "deepseek-chat"
```

支持所有 OpenAI 标准格式的厂商（DeepSeek、智谱AI、Moonshot、OpenAI、Groq、硅基流动、Gemini、OpenRouter 等），只需修改 `api_url` 和 `model` 即可切换。

### 3. 测试

```
/kila 你好
```

看到 AI 回复即配置成功。

> 重载配置使用 `/kilacraft reload`，重载知识库使用 `/kilacraft knowledge reload`，重载人格使用 `/kilacraft personalities reload`。

## 智能对话

### 三种交互模式

```
# 命令模式
/kila 怎么获得钻石？

# 连续对话模式
/kilacraft chat
> 我想建个农场
> AI: 好主意！你想种什么作物？

# 关键词触发（公共频道）
@ai 这个怎么做？
```

命令别名：`/kilacraft`、`/kila`、`/ai`、`/zm`

### 流式输出

AI 回复逐字实时显示，消除等待感：

```yaml
output:
  stream:
    enabled: true
```

支持 5 种输出载体，按场景独立配置：

|        载体       |     效果     |    适合场景   |
| :-------------: | :--------: | :-------: |
|   **SIDEBAR**   | 右侧边栏，不遮挡视野 | 长文本回复（推荐） |
|  **BOSS\_BAR**  |    顶部横条    |   中等长度文本  |
| **ACTION\_BAR** |    物品栏上方   |   短文本提示   |
|     **CHAT**    |     聊天栏    |    默认方式   |
|    **TITLE**    |    屏幕中央    |   短文本高亮   |

### AI 回复音效

AI 开始回复时自动播放提示音效，仅触发玩家可听到：

```yaml
output:
  sound:
    enabled: true
    sound_name: "ENTITY_PLAYER_LEVELUP"
    volume: 0.5
    pitch: 1.2
```

## 知识库增强

让 AI 了解你的服务器规则、玩法、FAQ。只需在 `plugins/Kilacraft-AI/knowledge/` 目录放入 Markdown 或 TXT 文件：

```markdown
# server_rules.md

## 如何获得领地？
使用 /claim 命令来圈定你的领地。需要至少 10 个金币。
```

执行 `/kilacraft knowledge reload` 加载，玩家提问时 AI 会自动检索并引用。

支持自定义词典，添加服务器特有术语可显著提升检索准确度。

## 玩家画像系统

AI 自动分析玩家的对话历史，为每个玩家建立五维度行为画像，并在后续对话中动态调整沟通风格。**AI 越来越懂你的玩家。**

### 五个画像维度

| 维度 | 说明 | 示例 |
| :---: | :---: | :---: |
| 游戏风格 | 玩家的玩法偏好 | 战斗型、探索型、建造型 |
| 性格特征 | 行为模式 | 友好、幽默、直接 |
| 内容偏好 | 感兴趣的话题 | 经济交易、副本攻略、装备打造 |
| 沟通风格 | 交流方式 | 简短直接、喜欢详细解释 |
| 特别观察 | AI 自由观察 | "该玩家最近对附魔系统特别感兴趣" |

### 工作方式

- 玩家登录/退出时自动触发分析（三重门控，防止浪费 API 调用）
- 分析数据来源为玩家与 AI 的真实对话（排除 NPC 对话和问候消息）
- 结果自动注入后续对话的系统提示词，AI 会据此调整回复风格
- 配置项位于 `llm.yml`：

```yaml
agent:
  profile:
    enabled: true
    min_interval_minutes: 30    # 最小分析间隔
    min_message_delta: 20       # 最小新增消息数
```

## 社交关系系统

自动追踪玩家间的交互行为，构建社交关系图谱，让 AI 感知玩家之间的社交关系。

### 追踪的交互类型

| 交互类型 | 触发方式 | 社交权重 |
| :---: | :---: | :---: |
| 私聊 | `/msg` 私聊消息 | 高 |
| TPA 传送 | `/tpa` 传送请求 | 较高 |
| 技能交互 | 通过 AI 协作完成任务 | 中 |

### 社交强度计算

关系强度采用递减累加算法——新增交互对关系的贡献随已有强度递减，防止少数玩家刷出极高值。长期不互动的关系会自然衰减。

### 效果

- 好友间的里程碑事件（击杀 BOSS、完成袭击、宠物战死等）会出现在对方的登录问候中
- AI 能感知"谁和谁是朋友"，在对话中自然提及好友动态
- 社交技能白名单可在 `config.yml` 中配置：

```yaml
social:
  skill_whitelist:
    - "market_action"
    - "cmi"
    - "AFKTask"
```

## AI 登录问候

玩家登录时 AI 自动发送个性化问候语。基于画像、离线事件和好友动态，每次问候都是独一无二的。

### 首次登录

欢迎新玩家，介绍 AI 助手功能。支持自定义服务器信息（在 `greeting.yml` 中配置 `server_info`）。

### 回归登录（三大分类数据聚合）

| 分类 | 数据来源 | 示例 |
| :---: | :---: | :---: |
| 自有事件 | 玩家离线期间服务器上发生的事 | 商品卖出、收到款项 |
| 好友动态 | 好友离线期间的里程碑 | 好友击杀了末影龙 |
| 游玩亮点 | 上次问候后的重要事件 | 宠物战死、触发图腾、击杀监守者 |

### 配置示例

```yaml
# greeting.yml
greeting:
  enabled: true
  delay_ticks: 100               # 登录后延迟（ticks）
  max_own_offline_events: 10     # 玩家离线事件最大条数
  max_friend_offline_events: 5   # 好友动态最大条数
  max_summary_events: 3          # 游玩亮点最大条数
  greeting_cooldown_minutes: 30  # 问候冷却（分钟）
  server_info: "你的服务器介绍"    # 可选，新玩家问候时提及
```

### 效果示例

```
# 首次登录
嘿 Hub，欢迎来到风铃雪途！我是你的AI帮手，直接 /ai 就能找我。
我能帮你查物品、逛市场、挂机做任务，有啥问题尽管问。

# 回归登录（离线 3 天）
欢迎回来！你上架的钻石卖出去了。你的好友 Steve 击杀了末影龙，Hub 现在也在线。

# 掉线重连（离线 10 秒）
嘿，刚走就回来啦？
```

## 数据库持久化

同时支持 H2 嵌入式数据库和 MySQL，重启不丢失数据。

### H2 嵌入式（默认）

零配置开箱即用，数据库文件存储在 `plugins/Kilacraft-AI/data/`。

### MySQL

多子服共享数据时推荐：

```yaml
# database.yml
database:
  type: mysql
  host: localhost
  port: 3306
  database: kilacraft
  username: root
  password: your-password
```

执行 `/kilacraft reload` 即可热切换，失败自动回退。

### 持久化内容

| 数据 | 说明 |
|------|------|
| 对话历史 | 玩家与 AI 的所有对话，30 秒批量刷盘 |
| 玩家画像 | 五维度行为分析结果 |
| 社交关系 | 玩家间交互强度与类型 |
| 服务器事件 | 死亡、成就、交易等里程碑 |
| 技能审计 | 所有 Skill 执行记录 |

> 数据保留天数可在 `database.yml` 中配置，过期数据自动清理。

## 人格系统与 NPC 对话

### 人格配置

在 `personalities.yml` 中定义不同风格的 AI 人格：

```yaml
common_prompt: "你是 Minecraft 服务器的 NPC，正在和玩家 {player} 对话。"

狐狸: |
  你是一只聪明的狐狸 NPC，说话俏皮可爱。
  喜欢用"~"结尾，经常使用表情符号。
```

### NPC 智能对话

有两种方式让 MythicMobs NPC 拥有独立人格：

**方式一：回调命令**（推荐）

```yaml
# MythicMobs 技能配置
fox_npc_skill:
  Skills:
  - cmd{c="kilacraft plugins 狐狸 服务器的规则是什么 <caster.uuid> myplugin handle_ai {response} <caster.name>"} @self
```

**方式二：MythicMobs 占位符**

```yaml
fox_npc_skill:
  Skills:
  - cmd{c="kilacraft plugins 狐狸 服务器的规则是什么 <caster.uuid>"} @self
  - message{msg="<caster.ai.answer{type=狐狸}>"} @trigger
```

> 插件命令仅限控制台执行，每个 `UUID_人格` 组合有独立历史记录。

## 安全机制

### 玩家数据隔离

内置非合作式安全过滤机制，在每次 Skill 执行前自动运行：

- 扫描 Skill 参数中的所有值，检测是否包含其他在线玩家名
- 非本人且不在白名单 → 自动替换为当前玩家名（消毒），Skill 继续执行
- 白名单机制：CMI 传送请求、挂机任务等需要操作其他玩家的 Skill 已预置白名单

### 第三方 Skill 防护

即使第三方 Skill 尝试操作其他玩家，安全过滤器也会自动消毒。

### Skill 全球台账

所有已注册的第三方 Skill 的使用统计与安全审查状态可在 [Skill 全球台账](https://axy-yxa.github.io/Kilacraft-AI/skill-registry.html) 实时查看。通过审查的 Skill 会标记为 🟢 已审查，服主可据此判断是否安装。

## 常见问题

**Q: API 费用高吗？**

以 DeepSeek 为例，单次对话约 ¥0.001-0.002。设置冷却时间（默认 5 秒）可有效控制成本。

**Q: 支持哪些 LLM？**

所有 OpenAI 标准格式的厂商均可。不支持思考/推理模型（如 deepseek-reasoner、o1）。

**Q: 会卡服吗？**

不会。所有 API 请求异步执行，内存占用 8-50 MB，HTTP 连接池复用，支持流式响应降低延迟。

**Q: 如何更新？**

备份 `plugins/Kilacraft-AI/` 目录保留配置，替换 JAR 文件，重启服务器。
