## 快速开始

### 1. 安装

下载最新的 `Kilacraft-AI.jar`，放入服务器 `plugins/` 目录，启动服务器。

### 2. 配置 API

编辑 `plugins/Kilacraft-AI/llm.yml`，填入你的 LLM API 信息：

```yaml
llm:
  api_url: "https://api.deepseek.com/v1/chat/completions"
  api_key: "your-api-key"
  model: "deepseek-chat"
```

支持所有 OpenAI 标准格式的厂商（DeepSeek、智谱AI、Moonshot、OpenAI、Groq、硅基流动、Gemini、OpenRouter 等），只需修改 `api_url` 和 `model` 即可切换。

### 3. 测试

```
/kila 你好
```

看到 AI 回复即配置成功。

> 重载配置使用 `/kila reload`，重载知识库使用 `/kila knowledge reload`，重载人格使用 `/kila personalities reload`。

## 核心功能

### AI 智能对话

**三种交互模式：**

```
# 命令模式
/kila 怎么获得钻石？

# 连续对话模式
/kila chat
> 我想建个农场
> AI: 好主意！你想种什么作物？

# 关键词触发（公共频道）
@ai 这个怎么做？
```

命令别名：`/kilacraft`、`/kila`、`/ai`、`/zm`

**流式输出与载体选择：**

AI 回复逐字实时显示，消除等待感。支持 5 种输出载体，按场景独立配置：

|        载体       |     效果     |    适合场景   |
| :-------------: | :--------: | :-------: |
|   **SIDEBAR**   | 右侧边栏，不遮挡视野 | 长文本回复（推荐） |
|  **BOSS\_BAR**  |    顶部横条    |   中等长度文本  |
| **ACTION\_BAR** |    物品栏上方   |   短文本提示   |
|     **CHAT**    |     聊天栏    |    默认方式   |
|    **TITLE**    |    屏幕中央    |   短文本高亮   |

**AI 回复音效：**

AI 开始回复时自动播放提示音效，仅触发玩家可听到。配置位于 `output.yml`：

```yaml
output:
  sound:
    enabled: true
    sound_name: "ENTITY_PLAYER_LEVELUP"
    volume: 0.5
    pitch: 1.2
```

### 知识库增强

让 AI 了解你的服务器规则、玩法、FAQ。只需在 `plugins/Kilacraft-AI/knowledge/` 目录放入 Markdown 或 TXT 文件：

```markdown
# server_rules.md

## 如何获得领地？
使用 /claim 命令来圈定你的领地。需要至少 10 个金币。
```

执行 `/kila knowledge reload` 加载，玩家提问时 AI 会自动检索并引用。支持自定义词典，添加服务器特有术语可显著提升检索准确度。

### 联网搜索

让 AI 突破训练数据截止日期的限制，实时查询 Minecraft 版本更新、mod 推荐、今日金价/汇率、球赛比分、Wiki 百科等。内置 **9 家搜索引擎供应商**，按服务器语言自动路由（`provider: auto`），也可手动指定：

- 国内 5 家：智谱 AI、百度千帆、火山引擎豆包、七牛云百度、阿里云百炼 IQS
- 国际 4 家：Tavily、Brave、Exa、You.com

多家均有免费额度，零成本起步；支持配置多家互为备份。服主只需在 `web.yml` 填一家 API Key 即可用。支持时间范围筛选（今天/最近一周/最近一月）、自动多步搜索（复杂问题拆成最多 5 个子搜索）。需 `kilacraft.websearch` 权限（默认所有玩家可用，但需服主配置 API Key 才生效）。

### 网页抓取

丢一个具体网址给 AI，AI 会抓取该网页正文、读完、再回答你针对该页面的问题。例如"帮我看看这个教程网页讲了什么""这个 mod 维基页面里的合成配方是什么"。与联网搜索互补：搜索是给关键词找网页列表，抓取是给具体网址读正文。

**零配置无需任何 API Key**，开箱即用。内置企业级 SSRF 安全防护（内网地址拦截、防 DNS 重绑定、强制 HTTPS + 逐跳重定向复检、响应体字节级硬限制），服主可放心开启。需 `kilacraft.webfetch` 权限（默认所有玩家可用）。配置在 `web.yml` 的 `web.fetch` 段。

### 对话推荐

AI 回复完毕后，在聊天框下方追加 1~5 个"你可能还想问"的可点击推荐问题，点击即以命令发送，无需手打。基于多轮对话历史 + 当前可用技能摘要智能生成，强制"宁缺毋滥"（不确定就不输出）。

**只在命令模式触发，连续对话模式不触发**——保护"像聊天一样自然"的沉浸感。玩家可 `/kila suggestion off` 关闭（默认开启，无需权限）；服主可在 `behavior.yml` 的 `suggestion:` 段配置推荐数量、超时、排除场景与技能、展示文案。

## 进阶功能

### 玩家画像与社交

**玩家画像**：AI 自动分析玩家的对话历史，为每个玩家建立八维度行为画像，并在后续对话中动态注入画像摘要作为参考上下文。**AI 越来越懂你的玩家。**

| 维度 | 说明 | 示例 |
| :---: | :---: | :---: |
| 游戏风格 | 玩家的玩法偏好 | 战斗型、探索型、建造型 |
| 性格特征 | 行为模式 | 友好、幽默、直接 |
| 兴趣偏好 | 感兴趣的领域和活动 | 经济交易、红石、建筑 |
| 交互禁忌 | 不喜欢的内容或行为 | 不要称呼名字、不要催促 |
| 回复偏好 | 期望 AI 的回复方式 | 简短直接、不用 emoji |
| 空间记忆 | 提到的地点、基地位置 | 主基地在沙漠 (1200,64,-800) |
| 已知事实 | 玩家明确声明的事实 | Steve 是好友、家在沙漠神殿旁 |
| 特别观察 | AI 自由观察 | "该玩家最近对附魔系统特别感兴趣" |

玩家登录/退出时自动触发分析（三重门控，防止浪费 API 调用）。配置项位于 `llm.yml`：

```yaml
agent:
  profile:
    enabled: true
    min_interval_minutes: 30    # 最小分析间隔
    min_message_delta: 20       # 最小新增消息数
```

**社交关系**：自动追踪玩家间的交互行为（私聊、TPA、技能交互），构建社交关系图谱。关系强度采用递减累加算法，长期不互动的关系会自然衰减。

- 好友间的里程碑事件（击杀 BOSS、完成袭击、宠物战死等）会出现在对方的登录问候中
- AI 能感知"谁和谁是朋友"，在对话中自然提及好友动态

### 登录问候

玩家登录时 AI 自动发送个性化问候语。基于画像、离线事件和好友动态，每次问候都是独一无二的。

**首次登录**：欢迎新玩家，介绍 AI 助手功能。支持自定义服务器信息（在 `behavior.yml` 的 `greeting` 段配置 `server_info`）。

**回归登录（三大分类数据聚合）：**

| 分类 | 数据来源 | 示例 |
| :---: | :---: | :---: |
| 自有事件 | 玩家离线期间服务器上发生的事 | 商品卖出、收到款项 |
| 好友动态 | 好友离线期间的里程碑 | 好友击杀了末影龙 |
| 游玩亮点 | 上次问候后的重要事件 | 宠物战死、触发图腾、击杀监守者 |

```
# 首次登录
嘿 Hub，欢迎来到风铃雪途！我是你的AI帮手，直接 /ai 就能找我。
我能帮你查物品、逛市场、挂机做任务，有啥问题尽管问。

# 回归登录（离线 3 天）
欢迎回来！你上架的钻石卖出去了。你的好友 Steve 击杀了末影龙，Hub 现在也在线。

# 掉线重连（离线 10 秒）
嘿，刚走就回来啦？
```

### 人格系统与 NPC 对话

在 `personalities.yml` 中定义不同风格的 AI 人格，配合 MythicMobs 可让 NPC 拥有独立人格和对话能力：

```yaml
common_prompt: "你是 Minecraft 服务器的 NPC，正在和玩家 {player} 对话。"

狐狸: |
  你是一只聪明的狐狸 NPC，说话俏皮可爱。
  喜欢用"~"结尾，经常使用表情符号。
```

**NPC 对话方式：**

方式一（回调命令，推荐）：
```yaml
fox_npc_skill:
  Skills:
  - cmd{c="kilacraft plugins 狐狸 服务器的规则是什么 <caster.uuid> myplugin handle_ai {response} <caster.name>"} @self
```

方式二（MythicMobs 占位符）：
```yaml
fox_npc_skill:
  Skills:
  - cmd{c="kilacraft plugins 狐狸 服务器的规则是什么 <caster.uuid>"} @self
  - message{msg="<caster.ai.answer{type=狐狸}>"} @trigger
```

> 插件命令仅限控制台执行，每个 `UUID_人格` 组合有独立历史记录。

### 玩家自定义监听（WatchSkill）

用一句自然语言设定"自动盯梢"，条件满足或事件发生时 AI 主动提醒你。能力比旧挂机任务系统更强、更安全：

```
玩家: 帮我盯铁锭到 64 个
AI: 好的，铁锭达到 64 个时提醒你。

[铁锭凑够 64 个时...]
🔔 你的铁锭已经达到 64 个了。
```

**两类监听：**

- **条件监听**：盯数值或状态——"帮我盯铁锭到 64 个""血量低于 30% 提醒我""余额到 10000 通知我"。支持监听内置技能的只读查询（Bukkit 统计、CMI、市场查询、原版 API），运行时自动识别取值类型（数值/布尔/字符串）。
- **事件监听**：盯 11 种高价值游戏事件——熔炉烧好、作物成熟、击杀 BOSS、附近生成实体、玩家死亡、传送、经验升级、切换世界、破坏方块、钓鱼、聊天关键词。

触发后**只通知 AI，不自动执行操作**（比旧挂机任务更安全，不会在玩家离线时乱操作）。玩家短暂掉线（5 分钟内）重连，监听自动恢复。

通过全局单例事件监听器 + 反向索引优化性能，无人订阅时事件零成本；同一玩家的所有条件监听合并为单个定时器。需 `kilacraft.watch` 权限（默认所有玩家可用）。每玩家上限：条件监听 3 个 / 事件监听 5 个 / 全服合计 200 个。配置在 `behavior.yml` 的 `watch:` 段。

### 跨玩家上下线订阅（PlayerWatchSkill）

用自然语言订阅好友的上线/下线通知——"Steve 上线告诉我""Alex 上下线都告诉我"。**能力比旧系统更强**：支持同时订阅多个玩家（旧系统一次只能盯一个）、自带防乱序（下线通知会取消尚未发出的上线通知，避免"下线早于上线"的倒序）、上线通知延迟 2 秒等玩家完全进服。

定位是玩家社交轻交互，订阅仅存内存不持久化，订阅者下线自动清空。需 `kilacraft.player_watch` 权限（默认所有玩家可用），每玩家上限 5 个订阅。

> 以上两大新系统（玩家监听 / 跨玩家订阅）**取代了旧版本的挂机任务系统**。旧系统的 `/kila afk` 命令、`kilacraft.afk` 权限、`afk_task` 配置段已移除。如曾依赖旧挂机任务，请改用这两个新系统。

### 服务器健康监控

基于 Spark 的实时服务器性能监控与 AI 智能诊断系统，守护线程 24/7 后台运行，异常自动检测与告警。

**自动监控：** 守护线程每 10 秒轮询 TPS/MSPT/CPU 指标，超过阈值自动启动 Spark Profiler 采样，完成后调用推理模型生成诊断报告。

**手动采样：** 主动排查问题时使用：

```bash
/kila profile start [30-120]    # 启动采样（秒）
/kila profile status            # 查看状态
/kila profile stop              # 中断并丢弃
```

**诊断报告：** 包含服务器状态概览、插件耗时与热点方法触发路径（self time）、AI 诊断结论与优化建议。报告保存在 `plugins/Kilacraft-AI/reports/`，永久保存。

**告警通知：** 支持游戏内通知 + Discord Webhook / 钉钉群机器人外部推送（仅自动模式）。可用 `/kila notify test` 测试通知渠道。

**历史查询：** 通过自然语言查询历史告警和报告：
- "过去一天服务器有什么告警？"
- "列出最近的诊断报告"
- "我昨天升级了 MythicMobs，帮我看看性能有没有改善"

> 完整配置指南见 `admin.yml`，需 Spark 插件 + 推理模型 API 密钥。Paper 1.21+/Folia/Purpur/Leaf/Pufferfish 已内置 Spark。

### 玩家行为分析

通过自然语言查询服务器的玩家生态，权限要求：`kilacraft.admin.player`。

- **在线趋势**："过去一周玩家在线趋势怎么样？" — 登录/登出时间分布
- **活跃排行**："查看最活跃的玩家排行榜" — 登录次数、在线时长、最近登录
- **新玩家流入**："过去一周有多少新玩家加入？" — 数量与时间分布
- **画像覆盖率**："AI 画像分析覆盖了多少玩家？" — 已分析/待分析数量
- **社交洞察**："查看玩家社交网络分析" — 关系总数、平均强度、孤立玩家
- **指定玩家社交关系**："查一下 Steve 的社交关系" — 指定玩家的社交关系详情、关系强度、互动频次

### 审计日志查询

通过自然语言查询 AI 技能的使用情况，权限要求：`kilacraft.admin.audit`。

- **执行记录**："查询玩家 Steve 使用了哪些技能" — 技能名称、参数、结果
- **使用统计**："查看技能使用统计排行" — 使用次数、成功/失败、平均耗时
- **错误追踪**："查看失败的技能执行记录" — 失败记录、错误信息、时间分布

### AI 数据查询

一组只读命令，让玩家查看自己的 AI 使用情况，管理员可查看任意玩家或全服。自查看依赖 `kilacraft.query.self`（默认所有人），查看他人 / 全服分别需要 `kilacraft.usage.other` / `kilacraft.history.other` / `kilacraft.memory.other`（默认 OP）。

- **用量统计** `/kila usage [玩家|all] [1d/3d/7d/30d]`：对话轮数、技能调用次数与成功率、热门技能 Top、活跃玩家 Top。默认查自己最近 7 天；`all` 查全服
- **对话历史** `/kila history [玩家] [页码] [-f]`：分页查看对话记录，页内按时间正序（旧→新）；`-f` 显示完整内容（默认超长内容会缩略）
- **玩家画像** `/kila memory [玩家]`：登录统计（首次 / 最近登录、登录次数、累计时长）+ AI 分析的八维度画像（暂未分析时不显示八维度）

> 离线玩家也可查询：输入玩家名即可，UUID 会在后台反查。

## AI 技能体系

AI 通过 Skill（技能）与服务器交互，每个 Skill 对应一类操作能力。所有 Skill 均为只读查询（除明确标注的写操作），细粒度权限控制。

**查看与手动执行技能：**

- `/kila skills [页码]`：列出你当前有权触发的技能清单（与 AI 聊天时的权限预过滤同源，只能看到自己能用的技能）
- `/kila run <技能名> <提示词>`：跳过意图识别，直接指定技能执行。用于精确触发某个技能或调试，例如 `/kila run market_query 查钻石价格`。无法解析意图时会自动降级为普通对话

### 能力总览

| 类别 | 能力 | 依赖插件 | 权限节点 |
| :---: | :--- | :---: | :---: |
| **Bukkit API** | 71 个内置只读接口：玩家物品栏/状态/信息、世界信息、服务器信息、环境感知 | 无 | `kilacraft.api.*` |
| **原版统计** | 80+ 原版累计统计查询（生涯记录），知识库驱动 BM25 检索，自动单位转换 | 无 | `kilacraft.bukkit_stats` |
| **全球市场** | 搜索/上架/领取/求购/下架/转账/拍卖/批量出售/批量收购（9 种操作） | GlobalMarketPlus | `kilacraft.market.*` |
| **CMI 集成** | 5 查询（家/地标/玩家信息/在线列表/AFK）+ 3 传送（家/地标/TPA） | CMI | `kilacraft.cmi.*` |
| **玩家监听** | 自定义条件/事件监听，11 种事件（详见上方进阶功能） | 无 | `kilacraft.watch` |

| **版本信息** | 查询插件版本、更新日志、新版本检测 | 无 | `kilacraft.admin.info` |

## 数据与安全

### 数据持久化

同时支持 H2 嵌入式数据库（默认，零配置）和 MySQL，重启不丢失数据。多子服共享数据时推荐 MySQL，执行 `/kila reload` 即可热切换，失败自动回退。

| 数据 | 说明 |
|------|------|
| 对话历史 | 玩家与 AI 的所有对话，30 秒批量刷盘 |
| 玩家画像 | 八维度行为分析结果 |
| 社交关系 | 玩家间交互强度与类型 |
| 服务器事件 | 死亡、成就、交易等里程碑 |
| 技能审计 | 所有 Skill 执行记录 |
| 画像快照 | 画像历史版本 |

> 数据保留天数可在 `database.yml` 中配置，过期数据自动清理。群组服数据隔离。

### 安全机制

- **玩家数据隔离**：内置非合作式安全过滤，扫描 Skill 参数中的所有值，非本人且不在白名单的玩家名自动替换（消毒）
- **第三方 Skill 防护**：即使第三方 Skill 尝试操作其他玩家，安全过滤器也会自动消毒
- **LLM 预算治理**：跨所有 LLM 入口的防失控兜底。按玩家维度统计每小时调用次数，超过阈值（默认 200 次/小时/玩家，可在 `llm.yml` 的 `budget_per_player_per_hour` 调整）触发 1 小时熔断。采用**二元熔断**——玩家主动请求（聊天/技能/任务）永不熔断，即使超预算也照常响应；被动调用（问候/推荐/主动提醒/第三方插件回调）在熔断窗口内统一拒绝。正常使用永远感知不到，只在异常工况（刷怪塔信号风暴、配置错误狂调、第三方插件失控）下兜底，保护玩家体验与服主的钱包。设为 0 或负数可完全禁用
- **WebFetch SSRF 防护**：网页抓取内置三重安全防护——内网地址拦截（默认禁止访问本机/局域网）、防 DNS 重绑定（IP 校验焊进 DNS 解析，消除"先检查后连接"的时间差漏洞）、强制 HTTPS + 逐跳重定向复检。服主可放心开启
- **Skill 全球台账**：所有已注册第三方 Skill 的使用统计与安全审查状态可在 [Skill 全球台账](https://axy-yxa.github.io/Kilacraft-AI/skill-registry.html) 实时查看，通过审查的 Skill 标记为已审查

### 开放 SPI 接口

第三方插件开发者可以通过 Skill SPI 接口将自己的功能暴露给 AI：

- **API JAR** 仅 5 KB（compileOnly 依赖）
- 实现 `SkillProvider` 接口即可注册自定义 Skill
- 内置错误隔离，第三方 Skill 异常不影响核心流程

详见 [Skill SPI 接入文档](Skill-SPI-接入文档.md)。

## 常见问题

**Q: API 费用高吗？**

以 DeepSeek 为例，单次对话约 ¥0.001-0.002。设置冷却时间（默认 5 秒）可有效控制成本。

**Q: 支持哪些 LLM？**

所有 OpenAI 标准格式的厂商均可。普通对话不支持思考/推理模型（如 deepseek-reasoner、o1），但服主管理功能的 AI 智能诊断支持配置推理模型（在 `admin.yml` 中配置）。

**Q: 会卡服吗？**

不会。所有 API 请求异步执行，内存占用 8-50 MB，HTTP 连接池复用，支持流式响应降低延迟。

**Q: 如何更新？**

备份 `plugins/Kilacraft-AI/` 目录保留配置，替换 JAR 文件，重启服务器。

**Q: 从旧版本升级，挂机任务系统去哪了？**

v2.2.0 移除了旧的挂机任务系统（`/kila afk` 命令、`kilacraft.afk` 权限、`afk_task` 配置段）。其能力被两个新系统**功能替代**：
- **玩家自定义监听（WatchSkill）**：用自然语言设定条件/事件监听，能力比旧系统更强
- **跨玩家订阅（PlayerWatchSkill）**：订阅好友上下线（替代旧系统的同名能力，支持多目标）
- 如有玩家依赖旧的 `/kila afk` 命令，请引导改用 `/kila watch` 相关能力或直接对 AI 说"帮我盯 xxx"

**Q: 联网搜索和网页抓取需要付费吗？**

网页抓取（WebFetch）**零配置、无需任何 API Key**，开箱即用。联网搜索（WebSearch）需要服主在 `web.yml` 配置至少一家搜索引擎供应商的 API Key，但内置的 9 家供应商均有免费额度，零成本起步。
