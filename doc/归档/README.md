## 为什么归档而不是删除

保留历史文档是为了：
- 让从旧版本升级的服主能查阅旧功能的完整说明，理解迁移路径
- 记录设计决策的演进过程，供维护者参考

归档文档的正文保持归档时的状态不变，仅在顶部添加了归档说明。
